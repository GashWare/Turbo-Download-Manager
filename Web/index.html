Zero-Delay Direct Random-Access I/O

Pre-allocates sparse physical disk space upon start. Worker threads stream byte offsets directly into the destination file via thread-safe OS file descriptors, completely eliminating post-download concatenation delays.

Pre-Allocation • Instant File Finalization

Bandwidth Limiter & Checksum Verifier

Token-bucket traffic shaping prevents ISP throttling and network congestion. Automatic post-download cryptographic hashing verifies file authenticity against SHA-256, SHA-512, SHA-1, and MD5 hashes.
